# Security Policy

## Supported Versions

Only the latest published minor/patch release of each Helm chart in this repository receives security updates.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities (such as privilege escalation, secret exposure, or insecure chart defaults) through public GitHub issues.

Instead, report them privately via one of the following channels:

- **GitHub Security Advisories:** Use the "Report a vulnerability" button under the **Security** tab of this repository.
- **Email:** Contact the maintainer directly at `maiducthang.it@gmail.com`.

Please include:
- The affected chart name and version (`Chart.yaml`).
- A minimal `values.yaml` or rendered manifest reproducing the issue.
- Potential impact and any suggested remediation.

We aim to acknowledge reports within 72 hours and provide a patched chart release as soon as a fix is verified.
